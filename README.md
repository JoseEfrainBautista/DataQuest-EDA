# DataQuest-EDA
📊 Portafolio de Análisis Exploratorio de Datos (EDA)
Este repositorio recopila proyectos donde se aplica técnicas de análisis exploratorio para comprender y visualizar datos.
Incluye:
* Limpieza, administración y transformación de datos.
* Estadísticas descriptivas.
* Visualizaciones interactivas y gráficas personalizadas.
* Uso de Python, Pandas, Matplotlib, Seaborn y Plotly.

El objetivo es descubrir patrones, relaciones y tendencias en diferentes conjuntos de datos para generar insights que faciliten la toma de decisiones.

El proyecto "Deliveryapp" contiene análisis exploratorio, análisis de embudos y pruebas A/B. Lo que busca evaluar el impacto que tendría un cambio en las fuentes de su aplicación. Constatamos si esta modificación implicará cambios significativos en los niveles de conversión de las distintas etapas del embudo que siguen sus usuarios.
